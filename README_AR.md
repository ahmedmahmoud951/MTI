## 🎯 نبذة عن المشروع

**مجموعة MTI الهندسية** هي شركة رائدة في مجال الحلول الهندسية المتقدمة تأسست عام **1969** في القاهرة، مصر.

### 📊 أرقام رئيسية
- **🏢 سنة التأسيس**: 1969 (أكثر من 55 سنة من الخبرة)
- **💰 الإيرادات السنوية**: 5+ مليار جنيه مصري
- **🌍 الوجود الإقليمي**: 6+ دول في منطقة الشرق الأوسط وشمال أفريقيا
- **👥 عدد الموظفين**: 1,000+ متخصص (60% مهندسين، 25% في المبيعات)
- **📍 الشركات المخدومة**: 3,000+ شركة بيع بالتجزئة والشركات الكبرى

### 🎯 الرؤية والرسالة

**الرؤية**: تمكين الناس بإحضار الابتكار والإلهام إلى حياتهم، مما يجعل حياتهم أسهل وأفضل.

**الرسالة**: أن تصبح الشركة الأولى للتكنولوجيا في منطقة الشرق الأوسط وشمال أفريقيا خلال خمس سنوات بتقديم حلول تحدث فرقاً حقيقياً.

## ✨ الميزات الرئيسية

### 🏗️ خدمات البنية التحتية الذكية

1. **🎥 أنظمة المراقبة بالفيديو (CCTV)**
   - نشر شامل من المنشآت البسيطة إلى الحرم الجامعي المعقد
   - 313,200+ جهاز مراقبة مُنشر
   - تكامل مع أجهزة الحرارة والـ PTZ

2. **🔐 التحكم في الوصول**
   - تحكم فيزيائي وإلكتروني متقدم
   - التكامل مع الأنظمة العالمية

3. **🏙️ المدن الذكية والآمنة**
   - برامج على مستوى الدول
   - أول مدينة ذكية آمنة في مصر (ACUD)

4. **🛡️ الأمن المحيطي**
   - دفاع متعدد الحساسات
   - رادار + كاميرات بعيدة المدى + تصوير حراري

5. **⚓ أمن الموانئ والمطارات**
   - حلول بحرية وجوية
   - تغطية محيطة وداخلية

6. **🧠 تحليل الفيديو بالذكاء الاصطناعي**
   - كشف الوجوه والمركبات والأسلحة
   - تحسين الاستجابة للحوادث

7. **🚦 المرور الذكي والتعريفات**
   - منصات متكاملة للتعريفات والتذاكر والمواقف
   - محرك ANPR/LPR داخلي

8. **🖥️ الأمن السيبراني**
   - حماية الطرفيات والتطبيقات والشبكات
   - حماية عملية خاصة (OT Protection)

9. **🔗 التكامل التكنولوجي**
   - تكامل سلس بين الأنظمة المختلفة
   - الأنظمة الحرجة والموثوقة

### 🌐 التجربة التفاعلية

- **🎮 تصور ثلاثي الأبعاد تفاعلي**: استكشاف ثلاثي الأبعاد للمباني والمشاريع
- **📊 لوحة تحكم مباشرة**: مقاييس وبيانات في الوقت الفعلي
- **🤖 مساعد ذكي**: روبوت محادثة مدعوم بالذكاء الاصطناعي
- **📱 تصميم متجاوب**: مُحسّن لجميع الأجهزة
- **✨ رسومات متحركة سلسة**: تحريكات Framer Motion الاحترافية

### 🎨 واجهة المستخدم

- **🌙 مظهر سايبر بانك**: تصميم داكن حديث بتدرجات ملونة
- **🎯 تجربة مستخدم محسّنة**: واجهات بديهية وسهلة الاستخدام
- **♿ إمكانية الوصول**: متوافق مع معايير WCAG 2.1

## 🚀 البدء السريع

### 📋 المتطلبات
- **Node.js**: الإصدار 16.0 أو أحدث
- **npm** أو **yarn**: مدير الحزم
- **Git**: للتحكم في الإصدارات
- **محرر نصوص**: VS Code أو أي محرر آخر

### 🔧 خطوات التثبيت

1. **استنساخ المستودع**
   ```bash
   git clone https://github.com/mtiengineering/website.git
   cd mti-engineering
   ```

2. **تثبيت المكتبات**
   ```bash
   npm install
   # أو
   yarn install
   ```

3. **تشغيل خادم التطوير**
   ```bash
   npm run dev
   # أو
   yarn dev
   ```

4. **فتح في المتصفح**
   انتقل إلى `http://localhost:3000`

#### **3. آلية العمل (How It Works):**

```
المستخدم يتفاعل مع الواجهة
    ↓
يختار طبقة (Layer) أو وحدة (Module)
    ↓
setState يحدّث الحالة
    ↓
DigitalDistrict Component يُعاد رسمه
    ↓
Three.js Canvas يحدّث الأشكال:
  - تغيير الألوان
  - تحريك المكعبات
  - إضاءة ديناميكية
    ↓
بطاقات المشاريع تتحدّث
    ↓
معلومات النموذج النشط تُعرض
```

## 🐛 استكشاف الأخطاء

### **مشكلة شائعة: خطأ "document is not defined"**
- **السبب**: محاولة الوصول لـ DOM على الخادم
- **الحل**: أضف `'use client'` في أعلى الملف

### **مشكلة: صور لا تُحمّل**
- **السبب**: عنوان URL غير صحيح
- **الحل**: تحقق من `next.config.js` و permissions الصور

### **مشكلة: تحريكات بطيئة**
- **السبب**: تحريكات معقدة جداً
- **الحل**: استخدم `will-change` و `transform` بدلاً من `left`/`top`

### **مشكلة: الترجمة لا تعمل**
- **السبب**: متغيرات البيئة غير مضبوطة
- **الحل**: أنشئ `.env.local` وأضف المتغيرات
